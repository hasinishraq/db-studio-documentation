# Getting started

DB Studio installs like any desktop app and stores nothing outside your machine except what you
send to your own databases and, if you configure one, your AI provider.

1. [Install DB Studio](installation.md) for your platform.
2. [Add your first connection](first-connection.md) and run a query.
3. Explore the [user guide](../user-guide/index.md) for tables, diagrams, imports and the assistant.

!!! tip "No account, no cloud"
    DB Studio has no sign-in, no sync and no telemetry. Connection profiles, history and settings
    live in a local SQLite file; passwords and API keys live in your operating system's keychain.
