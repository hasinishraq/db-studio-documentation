# Light and dark

DB Studio has a dark and a light theme. **Settings → General → Theme** offers *Match the system*
(the default), *Dark* and *Light*. Everything works the same in both. Exported diagram images are
always light, whatever the theme.

| Dark | Light |
|---|---|
| ![General settings, dark](../assets/screenshots/105-settings-general.png){ .shot loading=lazy } | ![General settings, light](../assets/screenshots/147-light-settings-general.png){ .shot loading=lazy } |

Each tab below shows the same screen in both themes. Choosing *Light* on one switches every tab on
this page.
